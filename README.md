# Indonesian Hoax Detection Using Random Forest
A machine learning project for detecting hoax news in Indonesian written articles using **Random Forest** and topic modeling, with a comparison of single-stage and multistage approaches.

## 📌 Project Overview
This project was developed as part of my undergraduate thesis:

**“Deteksi Hoaks untuk Postingan Artikel Tulisan Berbahasa Indonesia Berbasis Topik Modelling Menggunakan Algoritma Random Forest”**
The project focuses on Indonesian hoax detection using text-based machine learning techniques.

## 🎯 Objectives
- Develop a machine learning approach to identify hoax news in Indonesian articles.
- Apply topic modeling as part of the text analysis process.
- Explore Random Forest for text classification.
- Compare single-stage and multistage approaches.

## 🛠️ Technologies
- Python
- Google Colab
- Pandas
- NumPy
- Scikit-learn
- Natural Language Processing (NLP)
- Random Forest
- Topic Modeling (single stage & multistage)

## 🚀 How to Run
1. Download the notebook and dataset from this repository.
2. Open [Google Colab](https://colab.research.google.com/).
3. Upload the `.ipynb` notebook to Google Colab.
4. Upload the dataset when required by the notebook.
5. Run the notebook cells in order.

## 📊 Dataset
The dataset used in this project is available in the repository as `deteksi_hoaks_dataset fix.csv`.
